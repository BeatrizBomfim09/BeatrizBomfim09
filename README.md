### ◈ SafeGate

Sistema escolar de gerenciamento de entrada e saída de alunos, desenvolvido para auxiliar no controle do ambiente escolar.

**Tecnologias:** Java, Spring Boot, HTML, CSS e banco de dados.

### ◈ Food Rescue

Plataforma voltada ao combate ao desperdício de alimentos, conectando mercados a entidades sociais para facilitar doações de produtos próximos do vencimento.

**Tecnologias:** Java, Spring Boot, Thymeleaf, HTML, CSS e SQL.
